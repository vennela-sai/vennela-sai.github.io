Project

Cognitive-Cane

IoT navigation assistant for the visually impaired

Edge sensorsCloud processingAudio guidance

Overview

Real-time navigation aid that processes visual sensor data into spoken guidance, combining edge sensing with cloud inference under practical field latency constraints.

Key points

  • ~5-second end-to-end response time in field conditions
  • Edge + cloud split for sensing and heavier perception
  • Audio instruction interface for accessibility

Design

Sensor streams are captured on-device; heavier vision/decision stages run in the cloud; results return as concise audio cues. The engineering focus is reliable latency under real-world networking and lighting, not lab-only demos.
