Project

Graph-Based Persistent Memory

Architecture for large-scale conversational AI

Neo4jGAPOFastAPIsentence-transformersLouvainDocker

Overview

A wrapper-agnostic persistent memory layer that turns conversations into a Neo4j knowledge graph with semantic, entity, and temporal edges. Multiple LLM providers (Gemini, Qwen, Claude, DeepSeek, Codestral) share one graph. Graph-Aware Prompt Optimization (GAPO) ranks context with a convex combination of similarity, PageRank-proxy centrality, and Shannon entropy.

Key points

  • CRS 0.820 → 0.870 and Precision@10 0.50 → 0.60 vs two-tier baseline (Wilcoxon p < 0.001, n=500)
  • Sub-second Tier-1 retrieval at 50k+ nodes; linear scale to 100k+
  • Louvain + LLM summarisation: 40–60% node reduction
  • LongMemEval-S macro QA 45.9%, R@10 0.61; LoCoMo 53.9%; PersonaMem 62.5%
  • Integrity analyzer scores responses 0–100 against retrieved memory

Motivation

LLMs lack persistent memory across sessions. Flat RAG treats turns as independent vectors and misses relational structure: shared entities, temporal order, and hubs that later turns depend on. Prior memory systems are typically single-provider and score retrieval by similarity alone.

System

Turns become nodes with embeddings (all-MiniLM-L6-v2), entities (spaCy NER), and topics. Edges: SEMANTIC (sim > θ=0.82), ENTITY (shared NER), TEMPORAL (within-session order). Two-tier retrieval scans the latest L=500 nodes first; falls back to full scan if max similarity < 0.35.

GAPO(n) = α·s̃ + β·P̃ + γ·H̃ with defaults (0.5, 0.3, 0.2), calibrated by grid search on a held-out 200-query slice. Compression runs asynchronously above 10k nodes via Louvain; integrity checks run after generation for contradiction, unsupported claims, hallucination, and relevance.

Evaluation

Controlled split (n=500): significant CRS and Precision gains; ablation shows PageRank proxy and entropy each contribute. LongMemEval-S: GAPO+RAG 45.9% macro vs dense MiniLM 41.8% and BM25 34.2%, with strongest lifts on multi-session and temporal reasoning. LoCoMo overall 53.9% (parity with A-MEM); MemBench Factual-Participation 71.6%; PersonaMem 62.5% (above full-context GPT-4o by 1.1 pp on that config). Real-world integrity mean 86.4 (95% CI 84.9–88.0) over 240 sessions.
