Project

AI-Driven Dynamic OS Kernel

RL for scheduling, memory, and power

PythonRLSchedulingMemory management

Overview

Kernel prototype with AI-driven process scheduling, memory management, and adaptive power optimisation. Reinforcement learning replaces static heuristics so resource-allocation and scheduling track real-time workload behaviour.

Key points

  • AI-driven process scheduling and memory management
  • Adaptive power optimisation under shifting load
  • RL decisions instead of hand-tuned static policy rules
  • Outcome: responsive allocation without manual heuristic retuning

Design

Rather than fixed priority and allocation rules, the prototype learns scheduling and memory actions from observed workload dynamics, so the same kernel path stays useful as demand shifts instead of needing constant hand-tuning.
